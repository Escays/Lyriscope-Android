## Lyriscope for Spotify 1.0.6

小版本，但修的是一类会反复发生的问题：**你手动挑的歌词，凭什么要被一次设置保存清掉。**

### 手动选择现在真的被记住了

之前手动选的结果只存在于歌词缓存里。保存一次歌词提供商或翻译设置、清一次当前歌曲缓存，这份结果就跟着没了，下次进播放页静悄悄回到自动匹配——而"选完歌词顺手去调设置"恰恰是最常见的操作顺序。

现在每首歌的手动选择单独存一份（来源 + 条目 id），跟缓存分开：

- 缓存还在，就直接用缓存；
- 缓存没了（保存设置、清除单曲缓存），按记录**重新取一次**你选的那条，不会被自动结果顶掉；
- 清除当前歌曲缓存时，记录一并清掉，不会"清不掉"。

### 手动搜索结果按"能不能跟唱"排序

带时间轴的结果排在前面，纯文本其次，纯音乐（没有人声）最后。之前纯文本可能排在第一条，点下去得到一份不会滚动的歌词，很容易以为模块坏了。

### 安装

装 APK → LSPosed 里勾选 Spotify → 强制停止 Spotify 再打开。签名未变，可从 1.0.5 直接覆盖安装。
