## Lyriscope for Spotify 1.0.9

这一版两件事：**设置界面按 Miuix 重做了一遍**，以及把**中文曲库**正式接进来。

### 设置界面

原来的设置是「九张长页 + 一堆各写各的控件」，一页能滚十几屏，浅色主题下还有一批对比度问题。这次重排为 **5 组 13 页**，每页只放一类东西：

- **当前歌曲** / **歌词**（来源、翻译与注音、AI 服务、歌词增强）/ **外观**（歌词样式、背景与效果、歌词页元素）/ **播放**（LP 唱机、播放与手势）/ **应用**（通用、权限与数据、关于与鸣谢）
- 组件统一到一套自绘控件：胶囊开关、卡片行、分段控件、滑块、折叠行、确认框
- 开关按 Miuix 的量做：滑块 20dp、行程 4→25dp、按下放大到 22.5dp、弹性质感（约 260ms 收住）、切换有触感
- 长按「译文」弹出的翻译面板整块迁移：卡片行 + 胶囊开关 + 分隔线，并支持**左右滑动切换「当前歌曲 / 全局」**
- 浅色主题：输入框、控件底色、选中态、主按钮对比度全部修正；浮在封面上的面板不再出现纯白方块

模块里不再显示「LP 唱机」和「播放与手势」——那是独立播放器才有的页面；「保持屏幕常亮」移到了「歌词页元素」。

### 界面语言

「跟随系统语言」现在跟的是**手机**的语言，而不是宿主应用的语言。之前模块跑在 Spotify 进程里，取的是 Spotify 自己的语言——韩文版 Spotify 会让整个模块变成韩文。

### 歌词来源

- 网易云、QQ 音乐、酷狗接入来源列表，与 LRCLIB 并列；手动搜索同样可选
- QQ 音乐保留第二条取词路线，第一条拿不到时自动换
- 所有来源都没有结果时不再静默，会明确说「没有找到」而不是停在加载态
- 手动选定曲库后，翻译跟着这份词走，不会出现「词是 A、译文来自 B」

### 背景

- 纯色背景可以直接用**封面自己的颜色**，不再需要额外的覆盖开关
- 歌词页不再在文字后面播放视频

### 修复

- 歌词页在打开前崩溃的问题
- 间奏段落借用了别的歌的歌词
- 没有时间轴的歌词被当成逐行歌词，现在会指出是哪个开关在拦
- 曲名写在另一种文字里时匹配不到同一首歌
- 翻译对齐器丢失已配对的句子
- 一处标点在两处写得不一样

### 安装

- 模块：`Lyriscope-Spotify-v1.0.9.apk`，装好后在 LSPosed 里勾选 Spotify 作用域，**强制停止 Spotify 再打开**
- 独立应用：`Lyriscope-Android-v1.0.9-release.apk`，可以独立用，凭据只用于封面与曲目 ID，不填也能看歌词（需要通知使用权）

签名与 1.0.8 相同，可以直接覆盖升级。
