## Lyriscope for Spotify 1.0.1

给 Spotify 加一层歌词：逐句高亮、原文 / 译文 / 罗马音分层，加长按呼出的底部卡片、释义与注释、多来源取词和翻译。

这是本项目脱离 ivLyrics 后的第一个正式版本。

### 安装

1. 下载 `Lyriscope-Spotify-1.0.1-release.apk` 并安装
2. 在 **LSPosed** 里启用 **Lyriscope for Spotify**，作用域勾选 **Spotify**
3. 强制停止 Spotify，重新打开

**不需要重新打包 Spotify** —— 模块在运行时注入。装完如果 Spotify 里没有变化，先确认 LSPosed 里作用域是否勾上、再强制停止一次 Spotify。

### 1.0.1 修了什么

- **修复启动闪退**：点迷你播放器进入播放页时，内嵌卡片挂载会触发界面文案初始化；某个分组的韩语文案是空字符串，初始化直接抛异常，导致整个模块随宿主一起挂掉。现在缺翻译只会回退英文，不会再崩。
- 设置首页改成四组：**当前歌曲 / 歌词 / 显示与播放 / 应用**，副标题去掉重复项；致谢收进底部单独一页。

### 1.0.0 带来的变化

- 品牌与包名独立：模块 `dev.lyriscope.spotify`，独立应用 `dev.lyriscope.app`
- 「检查更新」改为指向本仓库，不会再把你导向上游 ivLyrics 的安装包
- 手动找歌词：LRCLIB / 网易云 / QQ 音乐 / 酷狗，整首替换歌词与时间轴
- 网络与地区预设（中国大陆 / 海外 / 自定义）＋ 连接体检，逐项说明哪条链路不通、不通会失去什么
- 设置主页底部新增致谢页

### 需要知道

- **签名**：这个 APK 用调试证书签名。后续版本会尽量沿用同一份签名，升级时若提示签名冲突，请先卸载旧版（卸载会清掉模块内保存的偏好）。
- **环境**：Android 8.0+，需要 LSPosed；在 Spotify 9.1.80 上验证通过。
- **非官方项目**：与 Spotify、ivLyrics 作者均无隶属关系。上游没有 LICENSE 文件，本项目同样不主张额外授权。
- 歌词、译文与视频来自第三方，版权归各自权利人，请自行确认使用范围。
