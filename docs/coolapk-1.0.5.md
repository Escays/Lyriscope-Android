## 长版（正文）

**标题备选**

1. 给 Spotify 补上逐句歌词：Lyriscope 上手记录
2. Spotify 的歌词终于能看了——Lyriscope 模块体验
3. 一个 LSPosed 模块，把 Spotify 的歌词变成能读的样子

**正文**

Spotify 官方歌词只有「一行行滚」，没有译文、没有罗马音、也不能单独翻某一句。Lyriscope 是一个 LSPosed 模块，直接叠在 Spotify 播放页上做这几件事：

- 逐句高亮，原文 / 译文 / 罗马音分三层显示
- 长按歌曲标题，弹出底部卡片：歌词与翻译、同步、视频背景、背景、曲库选择
- 长按译文，只翻当前这一句，或者换一个翻译引擎
- 点灯泡：歌曲简介、逐句歌词、文化背景注释
- 歌词不对时「手动找歌词」：LRCLIB / 网易云 / QQ 音乐 / 酷狗，选中一条整首替换

**装之前需要的**

- Android 8.0 以上，**已 root 并装好 LSPosed**（不是 LSPatch，也不需要重打包 Spotify）
- Spotify 客户端（我在 9.1.80 上验证的，太老的版本可能对不上注入点）

**三步装好**

1. 下载 `Lyriscope-Spotify-1.0.5-release.apk` 并安装
2. 打开 LSPosed → 启用「Lyriscope for Spotify」→ 作用域勾选 **Spotify**
3. 强制停止 Spotify（设置 → 应用 → Spotify → 强行停止），重新打开

装完进播放页看不到变化，基本都是第 2 步作用域没勾、或者没强制停止。模块是**运行时注入**，随时可以关掉它，Spotify 本身不会被改动。

**日常怎么用**

| 想做的事 | 怎么做 |
| --- | --- |
| 看当前歌曲的完整设置 | 长按歌曲标题 |
| 只看简介 / 逐句注释 | 点灯泡图标 |
| 单独翻一句 | 长按那句译文 |
| 换翻译引擎 | 长按「简体中文 / 查看原文」胶囊 |
| 歌词匹配错了 | 设置里「歌词与翻译」→ 手动找歌词 |
| 调主题 / 显示 | 设置首页 → 显示与播放 |

**国内网络先做一件事**

设置首页 → 应用 → 高级 → **网络与地区**，选「中国大陆」：

- 释义翻译会默认切到 Bing（Google 翻译在国内基本连不上）
- 歌词来源优先中文译词（网易云、QQ 音乐）
- 顺手点一下「连接体检」，它会告诉你哪几个域名不通、不通会失去什么功能

不用猜 IP，也不用科学上网才能用——网易云、QQ、酷狗的取词和 Bing 翻译在国内都是通的，只是 Genius（歌曲简介）和 Google 翻译需要代理。体检里 Genius 挂了的话，简介这块就用不了，其他功能不受影响。

**几个坑提前说**

1. **签名**：这个包用的是调试证书。以后升级如果提示签名冲突，得先卸载旧版，模块里的偏好会一起被清掉。
2. **只放了模块包**：独立应用（不依赖 Spotify 的那个）这次没有发布，需要自己编译。
3. **歌词版权**：歌词、译文、视频都来自第三方，版权归各自权利人，自己听着玩没问题，别拿去商用或者二次分发。
4. **非官方**：和 Spotify、和 ivLyrics 作者都没有隶属关系。这个项目是从 ivLyrics 分叉出来自己往下改的，改到最后干脆独立成新仓库了。
5. **歌词对不上是常事**：不同平台的同一首歌时长差几秒，自动匹配就会错行。别急着骂，用「手动找歌词」指定一条就行——选中的那条会被记住，切歌回来也还是它。
6. **歌词不动、点不了**：你选的那条大概是"纯文本"（只有文字、没有时间轴）。列表里带「同步」标记的才会跟随播放，换成网易云、QQ 这类平台源基本都有时间轴。

## 短版（动态 / 评论区转发用）

LSPosed 模块，装完勾上作用域、强制停止 Spotify 就生效，不用重打包。国内记得先去「设置 → 应用 → 高级 → 网络与地区」选中国大陆，翻译会切到 Bing，还带个连接体检告诉你哪条路不通。

只放了模块包，独立应用要自己编译。调试签名，以后升级可能要卸载重装。
